# KITT plugins

Generated by `kitt build-plugins`. Do not hand-edit: this whole tree is
rewritten on every run. Change the catalog in the `kitt` repo instead.

Marketplace: `kitt-marketplace` (version 1.0.0-dev.8)

## Install

```
/plugin marketplace add <path-or-repo>
/plugin install kitt-core@kitt-marketplace
```

Install `kitt-core` first: it carries the MCP server every other pack's
skills call. Add the rest as needed.

| Plugin | What it ships |
|--------|---------------|
| `kitt-core` | Foundation tools: mental models, debugging, todo management, planning |
| `kitt-angular` | Angular development: component patterns, testing, code review |
| `kitt-auditors` | Skill, command, and subagent quality auditors |
| `kitt-crew` | Universal four-role agent crew (scout, coder, tester, auditor): one REQ per run, API-contract-first (OpenAPI or GraphQL), spec-files-as-authority, coverage-gated. For any disciplined dev project (net-new, ongoing iteration, blocker fix, or frontend handoff). |
| `kitt-meta` | Tools for creating new commands, skills, agents, and hooks, plus capturing hard-won knowledge as reusable skills |
| `kitt-python` | Python development: FastAPI, AI integrations (Bedrock, Vertex, Pinecone), testing, packaging |

## Prerequisite: uv

`kitt-core` runs its MCP server through [uv](https://docs.astral.sh/uv/).
uv is a static binary, installs into your user profile, needs no admin
rights, and provisions its own Python, so nothing else is required.

- Windows: `powershell -c "irm https://astral.sh/uv/install.ps1 | iex"`,
  or `winget install astral-sh.uv`
- macOS: `brew install uv`
- Linux: `curl -LsSf https://astral.sh/uv/install.sh | sh`

On Windows, Claude Code bundles Git Bash, so the bootstrap shim and the
pack scripts run there unchanged.

The server ships a `uv.lock`, so first MCP launch installs exactly the
pinned versions and takes a few seconds. Later launches reuse the
resolved environment.
